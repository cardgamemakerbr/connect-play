Regras Para IA

1. Tuda vez que realizar um ajuste atualise a documentação
2. Revise os requisitos do productowner e do README.md antes de executar uma tarefa
3. Se tiver dúvidas, pergunte ao productowner
4. Mantenha o código limpo e organizado
5. Teste suas alterações antes de enviar o código
6. Faça commits frequentes e com mensagens claras
7. Siga as melhores práticas de desenvolvimento
8. Ao realizar commit faça nas branch pertinentes dev, release e main
9. Ao realizar uma correção crie um issue
10. todas os commit na main ser solicitados antes de ser executados
