Regras Para IA

01. Todas as vez que realizar um ajuste atualise a documentação.
    - Ajuste tambem a versão do projeto na documentação.
02. Revise os requisitos do productowner e do README.md antes. de executar uma tarefa.
03. Se tiver dúvidas, pergunte ao productowner.
04. Mantenha o código limpo e organizado.
05. Teste suas alterações antes de enviar o código.
06. Faça commits frequentes e com mensagens claras.
07. Siga as melhores práticas de desenvolvimento.
08. Ao terminar de realizar a tarefa pode executar o docker .para testar o projeto.
09. Ao realizar commit faça nas branch pertinentes dev, release e main;
    - dev : correções edição de novas funçoes
    - release : correção de bugs e ajustes
    - main : versão final, somente merge de release
10. Ao realizar uma correção crie um issue.
11. todas os commit na main ser solicitados antes de ser executados.
12. se um arquivo file dentro da pasta productowner estevier no nome "-completado" pode ignorar a leitura deste arquivo.
13. se dentro de uma tarefa de um arquivo file dentro da pasta productowner estevier no nome "-completado" pode ignorar a execução desta tarefa.
